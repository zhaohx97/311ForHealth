# 311 for Health

Companion repository for *Emergent Behavioral Signals in Civic Feedback Decode Neighborhood Health Phenotypes*. The study combines 21M service requests from ten US cities (2019–2022 records), 27 standardized complaint categories, eight ACS variables, and 21 CDC PLACES health measures across 5,252 census tracts (2020–2023 releases). The primary analysis pairs 2022 complaints with the 2023 PLACES release.

For the repository structure, figure reproduction instructions, and key analytical settings, see [Reproducibility](Code/Reproducibility.md).
